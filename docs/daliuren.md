# 大六壬模块：定位、交互与实现口径

> 代码出口：`src/utils/daliurenCore.ts`（起课）、`src/utils/daliurenReading.ts`（判读）、`src/pages/Daliuren.tsx`（渲染）。
> 页面不写第二份判据——改判读只改前两个文件。

## 一、定位

大六壬是「三式」（太乙、奇门、六壬）中**专断人事**的一门，古称「人事之王」。放进爻一爻的占卜区，它的位置不是「又一个随机卦」，而是分层：

| 板块 | 粒度 | 强项 | 什么时候用它 |
| --- | --- | --- | --- |
| 六爻 | 一卦一问 | 单点成败、快 | 有个明确的是非题（成不成、来不来） |
| 梅花易数 | 一物一卦 | 触机、当下感应 | 临时起意、想换个角度看 |
| 大六壬 | 一课多断 | **过程分段**（初/中/末传）、细节多 | 想看清「这事分几步、卡在哪一步、谁在中间」 |
| 灵签 | 一签一答 | 情绪安抚、签文意象 | 想要一句话的方向感 |

产品上刻意做「重」：盘面信息量大、术语多，但**结论层仍然只给一句人话 + 依据清单**，与其它三板块共用同一把吉凶刻度（`divinationCore.verdictOf`）。这样同一件事在四个板块得到的结论方向不会互相打架；若不一致，用户能直接看到分歧出在哪条依据上。

## 二、交互流程

1. **默念问题** → 起课（三选一）
   - 正时起课：用当下的年月日时，最正规；
   - 活时起课：时辰另取（如「忽然心动的那一刻」），月将仍按当天节气；
   - 随机起课：将、时都抽——适合心里没底时换个角度，页面明说「别反复抽」。
2. **看课盘总览**：日干支、时干支、月将（含定将的中气）、昼夜、贵人落宫与顺逆、课体。
3. **读课体一句话**：元首＝顺理成章、重审＝由内而起、涉害＝几条路都带伤、昴星＝悬着、伏吟＝原地打转、返吟＝翻来覆去。
4. **选主题看结论**：事业/爱情/亲情/财运/健康/学业，先给档位（大吉…凶）与一句白话，再给按权重排序的依据。
5. **展开盘面复核**：四课（事从哪里起）→ 三传（起因/过程/结果）→ 十二宫天地盘（气落在哪个位）→ 本盘看点（贵人、空亡、驿马）。
6. **重新起课**：一事一课，反复起课等于反复问，页面不鼓励。

信息层级刻意做成「结论在上、盘面在下」，避免新手一进来就撞上十二宫和天将。

## 三、起课算法口径

| 环节 | 采用的规则 | 备注 |
| --- | --- | --- |
| 月将 | 中气换将（雨水后亥将……大寒后子将） | 不采「节气换将」 |
| 天地盘 | 月将加于占时之上，十二支顺布 | 天盘是气的落位，地盘是位 |
| 四课 | 日干寄宫起一课，日支起三课，各取上神 | 寄宫：甲寅乙辰丙戊巳丁己未庚申辛戌壬亥癸丑 |
| 三传 | 九宗门：伏吟/返吟 → 贼克 → 比用 → 涉害 → 八专 → 别责 → 遥克 → 昴星 | 比用取「与日干同阴阳」，涉害取「归本位途中克我重数多者」，复等则阳日取干上神、阴日取支上神 |
| 天将 | 贵蛇雀合勾龙空虎常玄阴后 | 贵人临地盘亥子丑寅卯辰顺布，巳午未申酉戌逆布 |
| 贵人 | 甲戊庚牛羊、乙己鼠猴、丙丁猪鸡、壬癸兔蛇、六辛马虎 | 昼占（卯～申）用阳贵，夜占用阴贵 |
| 遁干/旬空/驿马 | 按日干支旬遁、旬空两支、日支三合局取马 | 三传逐位标注 |

⚠️ `lunar-typescript` 的节气表跨年时会把键写成拼音（`DONG_ZHI`、`DA_HAN`…），只按中文名过滤会漏掉跨年那几个中气，12 月下旬会被错判成「小雪将」。这一层已在 `monthJiangOf` 里做了别名归一，并有回归测试盯冬至换将。

## 四、判读口径

**先定类神，再算强弱**，不能拿三传直接套吉凶：

- 事业 → 官鬼（职位/上司）+ 父母（文书/平台）
- 爱情 → 男看妻财、女看官鬼；未设性别两星合看，**不默认男命**
- 亲情 → 父母 + 兄弟
- 财运 → 妻财 + 子孙（财源）
- 健康 → 官鬼（病，**反向计分**）+ 子孙（药与恢复）
- 学业 → 父母（文书）+ 官鬼（名次）

权重（乘主题极性后计入 `divinationCore` 的统一刻度）：

| 因子 | 分值 |
| --- | --- |
| 类神落初传 / 日干上神 / 中传 / 末传 / 日支上神 | +3 / +2.5 / +2 / +2 / +1.5 |
| 月建旺衰（旺 +2、相 +1.5、休 −1、囚 −1.5、死 −2） | 乘极性 |
| 类神旬空 | −2 |
| 类神乘驿马 | +1 |
| 三传递生 / 递克 | ±1.2 |
| 三传落空 ≥2 | −1.2 |
| 课体（元首 +1、涉害/遥克/昴星/别责/八专 −1、伏吟 −1.5、返吟 −1 或 0） | 按主题 |
| 天将吉凶倾向 | ±0.8，**不乘极性** |

主类神与次类神**合并**计分，不「取分高的那一个」——健康题若只留子孙，就会得出「只讲药、不讲病」的半截结论。

## 五、开源实现参考

| 项目 | 语言 | 可借鉴的点 |
| --- | --- | --- |
| [kentang2017/kinliuren](https://github.com/kentang2017/kinliuren) | Python | 最完整的开源六壬库：三传、四课、天地盘、神煞、课体识别 + Streamlit 排盘。本项目对照它的月将表、天将顺序、寄宫表与「比用取同阴阳」的实现 |
| [let-fate/liuren-ts-lib](https://github.com/let-fate/liuren-ts-lib) | TypeScript | 基于 `tyme4ts` 的六壬库（天地盘/四课/三传/遁干/神煞），与本项目技术栈最近；若日后要换掉自研引擎，这是首选替代 |
| [Crazycreate/liuyao](https://github.com/Crazycreate/liuyao) | TS | 六爻 × 六壬双盘互证；它的「排盘确定性计算、只有断卦用 AI」思路与本项目「判据不进页面、不交给模型」一致 |
| [hhszzzz/taibu](https://github.com/hhszzzz/taibu) | TS | 多术数 Agent，`daliuren` / `daliuren_lessons` 两个工具的字段设计可参考（四课上下、三传递生递克、神将与类神） |

**为什么没有直接引依赖**：`liuren-ts-lib` 依赖 `tyme4ts`，本项目该包精确锁 `1.3.9`；新增依赖要重建 lock，而 `^` 版本会漂，且 `@ziweijs/*` 被上游撤下的前车之鉴说明「外部包随时会消失」。所以起课引擎按上述口径自研（约 500 行），把开源库当作**算法对照与验收基准**——`daliuren.test.ts` 里的锚点盘（甲午日申时，元首课，三传酉→辰→亥）就是手算 + 对照核过的那一例。

## 六、已知边界与流派差异

1. **贵人表**：本项目取通行口诀「甲戊庚牛羊」（甲日昼贵丑）。另有「甲羊戊庚牛」一系（甲日昼贵未），属流派差异，不采但已在代码注释标注。
2. **涉害深浅**：本实现计「归本位途中克我重数」，重数相同再比「我克」；部分流派只计克我，或另设「见机/察微/缀瑕」细目。
3. **课体细目**：`kinliuren` 有励德、稼穑、龙战、元胎、斫轮等大量杂课；本项目只落到九宗门主干 + 结构课（伏吟/返吟/八专/别责），杂课不作判据。
4. **断课深度**：不做应期精确到日（只给「空亡待填实、驿马主快」这类方向），不给「某月某日必成」的伪精确。
5. 农历子时换日按 `getDayInGanZhiExact`（23:00 起算次日），与八字页的晚子时流派开关不联动——两个模块的用途不同，不强行统一。
