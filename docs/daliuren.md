# 大六壬模块：定位、交互与实现口径

> 代码出口：`src/utils/daliurenCore.ts`（起课）、`src/utils/daliurenReading.ts`（判读）、`src/pages/Daliuren.tsx`（渲染）。
> 页面不写第二份判据——改判读只改前两个文件。

## 一、定位

大六壬是「三式」（太乙、奇门、六壬）中**专断人事**的一门，古称「人事之王」。放进爻一爻的占卜区，它的位置不是「又一个随机卦」，而是分层：

| 板块 | 粒度 | 强项 | 什么时候用它 |
| --- | --- | --- | --- |
| 六爻 | 一卦一问 | 单点成败、快 | 有个明确的是非题（成不成、来不来） |
| 梅花易数 | 一物一卦 | 触机、当下感应 | 临时起意、想换个角度看 |
| 大六壬 | 一课多断 | **过程分段**（初/中/末传）、细节多 | 想看清「这事分几步、卡在哪一步、谁在中间」 |
| 灵签 | 一签一答 | 情绪安抚、签文意象 | 想要一句话的方向感 |

产品上刻意做「重」：盘面信息量大、术语多，但**结论层仍然只给一句人话 + 依据清单**，与其它三板块共用同一把吉凶刻度（`divinationCore.verdictOf`）。这样同一件事在四个板块得到的结论方向不会互相打架；若不一致，用户能直接看到分歧出在哪条依据上。

## 二、交互流程

1. **默念问题** → 起课（三选一）
   - 正时起课：用当下的年月日时，最正规；
   - 活时起课：时辰另取（如「忽然心动的那一刻」），月将仍按当天节气；
   - 随机起课：将、时都抽——适合心里没底时换个角度，页面明说「别反复抽」。
2. **看课盘总览**：日干支、时干支、月将（含定将的中气）、昼夜、贵人落宫与顺逆、课体。
3. **读课体一句话**：元首＝顺理成章、重审＝由内而起、涉害＝几条路都带伤、昴星＝悬着、伏吟＝原地打转、返吟＝翻来覆去。
4. **选主题看结论**：事业/爱情/亲情/财运/健康/学业，先给档位（大吉…凶）与一句白话，再给按权重排序的依据。
5. **看应期**：以类神（或未定主题时的发用）之支为锚，给出「主窗口 + 参考窗口」，月尺度（哪个月）与日尺度（最近哪一天）各给一次；节奏（快/平/慢）说明是哪条盘面事实决定的。
6. **展开盘面复核**：四课（事从哪里起）→ 三传（起因/过程/结果）→ 十二宫天地盘（气落在哪个位）→ 本盘看点（贵人、空亡、驿马）。
7. **重新起课**：一事一课，反复起课等于反复问，页面不鼓励。

信息层级刻意做成「结论在上、盘面在下」，避免新手一进来就撞上十二宫和天将。

## 三、起课算法口径

| 环节 | 采用的规则 | 备注 |
| --- | --- | --- |
| 月将 | 中气换将（雨水后亥将……大寒后子将） | 不采「节气换将」 |
| 天地盘 | 月将加于占时之上，十二支顺布 | 天盘是气的落位，地盘是位 |
| 四课 | 日干寄宫起一课，日支起三课，各取上神 | 寄宫：甲寅乙辰丙戊巳丁己未庚申辛戌壬亥癸丑 |
| 三传 | 九宗门：伏吟/返吟 → 贼克 → 比用 → 涉害 → 八专 → 别责 → 遥克 → 昴星 | 比用取「与日干同阴阳」，涉害取「归本位途中克我重数多者」，复等则阳日取干上神、阴日取支上神 |
| 天将 | 贵蛇雀合勾龙空虎常玄阴后 | 贵人临地盘亥子丑寅卯辰顺布，巳午未申酉戌逆布 |
| 贵人 | 甲戊庚牛羊、乙己鼠猴、丙丁猪鸡、壬癸兔蛇、六辛马虎 | 昼占（卯～申）用阳贵，夜占用阴贵 |
| 遁干/旬空/驿马 | 按日干支旬遁、旬空两支、日支三合局取马 | 三传逐位标注 |

⚠️ `lunar-typescript` 的节气表跨年时会把键写成拼音（`DONG_ZHI`、`DA_HAN`…），只按中文名过滤会漏掉跨年那几个中气，12 月下旬会被错判成「小雪将」。这一层已在 `monthJiangOf` 里做了别名归一，并有回归测试盯冬至换将。

## 四、判读口径

**先定类神，再算强弱**，不能拿三传直接套吉凶：

- 事业 → 官鬼（职位/上司）+ 父母（文书/平台）
- 爱情 → 男看妻财、女看官鬼；未设性别两星合看，**不默认男命**
- 亲情 → 父母 + 兄弟
- 财运 → 妻财 + 子孙（财源）
- 健康 → 官鬼（病，**反向计分**）+ 子孙（药与恢复）
- 学业 → 父母（文书）+ 官鬼（名次）

权重（乘主题极性后计入 `divinationCore` 的统一刻度）：

| 因子 | 分值 |
| --- | --- |
| 类神落初传 / 日干上神 / 中传 / 末传 / 日支上神 | +3 / +2.5 / +2 / +2 / +1.5 |
| 月建旺衰（旺 +2、相 +1.5、休 −1、囚 −1.5、死 −2） | 乘极性 |
| 类神旬空 | −2 |
| 类神乘驿马 | +1 |
| 三传递生 / 递克 | ±1.2 |
| 三传落空 ≥2 | −1.2 |
| 课体（元首 +1、涉害/遥克/昴星/别责/八专 −1、伏吟 −1.5、返吟 −1 或 0） | 按主题 |
| 天将吉凶倾向 | ±0.8，**不乘极性** |

主类神与次类神**合并**计分，不「取分高的那一个」——健康题若只留子孙，就会得出「只讲药、不讲病」的半截结论。

## 五、应期口径

应期层（`buildDaliurenTiming`）**不改吉凶**，只回答「大概什么时候见分晓」。四路取法 + 一条节奏修正，每条都必须落在盘面事实上：

| 取法 | 规则 | 落到页面 |
| --- | --- | --- |
| ① 定支 | 以**类神落点之支**为应期之支；未定主题时取**发用**（事之始） | 主窗口 |
| ② 空亡 | 该支落旬空 → 等**填实**（该支值月值日）或**冲实**（对冲之支） | 参考窗口 |
| ③ 落点 / 转折 | 末传为结果、中传为转折；三传成局则取该局**当令之季**（申子辰→冬、亥卯未→春…） | 参考窗口 |
| ④ 驿马 | 临日马主快主远 → 先按「日」论，别按月等 | 节奏 + 规则说明 |
| ⑤ 节奏修正 | 伏吟主慢（等冲）、返吟主快（但反复）、元首主顺、昴星/遥克/别责/八专主「够不着」 | `speed` 快/平/慢 |

两个尺度同时给：**月尺度**按「月建→目标支」的月距折算（`子月＝农历十一月`，月建以节气换）；**日尺度**按「日支→目标支」的天数折算（如甲午日问酉，最近的酉日＝3 天后）。近事看日、远事看月，这正是六壬「快在日、慢在月」的本意。

⚠️ 两条纪律（都有测试盯）：

1. **主窗口永远是 `windows[0]`，且只标一个「主」**。曾经的实现按「哪条规则先命中」排窗口，导致「末传＝本月」被排在「类神＝10 个月后」前面——旁证抢了正法的主位，用户会读成「本月就有信儿」。
2. **不采「三传支数相加取日数」一派**（子1丑2……相加得几天）。同一组三传在不同月份起点下能差好几个月，给的是**假精确**，用户会当承诺。所以只给「支 + 相对月数/天数」，并明写「不给具体某一天、不作承诺」。

主题不同 → 锚点不同 → 应期不同（事业锚官鬼、财运锚妻财、亲情锚父母、爱情按性别锚妻财/官鬼），这也是防套话的硬约束：换主题换了窗口才算数。

## 六、行动层口径

判读给「是什么」，应期给「什么时候」，行动层（`buildDaliurenActions`）给「**所以呢**」——找哪一类人、往哪个方向使劲、用什么方式推、哪里别撞。**不重新判吉凶**，只把前两层的结论翻成能做的事，且每条都带可核对的 `basis`（地支 / 天将 / 课体 / 驿马），用户觉得不对可以按依据自己改。

四条固定出口：

| kind | 取法 | 分档要点 |
| --- | --- | --- |
| 找人 | 类神所乘**天将** → 该找哪一类人；方位取该支的后天方位 | **天将取人必须按主题分三张表**，见下 |
| 方向 | 有驿马（三传临日马）→ 往马的方向动；无马 → 以类神落点为着力点，不必远行 | 锚点**不得落在旬空之支**（空＝不落实，指方向等于指虚位），退取三传中第一个不空的支 |
| 方式 | **课体**定走法（元首→走正规程序／重审→先理顺内部／比用→择一到底／涉害→挑伤最轻／遥克→先搭桥／昴星→等信号／别责→借力／八专→拉开距离／伏吟→别推／返吟→别反复改） | 措辞必须跨主题通用；课体落旬空时追加的**「先别……」提示按主题分档** |
| 避坑 | 四课单向压制 > 三传重空 > 凶将气质 > 伏吟 > 无坑可踩 | 凶将的提醒话术按主题分档 |

⚠️ 三条纪律（都有测试盯）：

1. **天将取人分三张表**：`JIANG_PERSON`（事业/亲情/财运/学业）、`JIANG_PERSON_MED`（健康）、`JIANG_PERSON_LOVE`（爱情）。同一颗「勾陈」在事业是「管旧账、跑流程的老经办」，在健康是「掌握旧病历的老医生」，在爱情是「牵着旧关系的人」——换主题不换人就是硬错。
2. **凶将不是人选**：天空 / 玄武 / 白虎 / 螣蛇描述的是**风险**，不是「该去找的人」。类神乘这四颗时「找人」走回落分支（按主题回落贵人 / 六合 / 青龙 / 朱雀），并明写「这一颗主风险，不是人选」。否则会写出「去找暗处的人」「去找有第三方没说清的人」这种逻辑错位的话。
3. **「空」的提醒也分主题**：同一句「这一步是空的」，事业是「别签字、落到纸面或定金上」，财运是「别付钱」，爱情是「别摊牌」，健康是「结果没出来别自己下结论」。让问健康的人「别付钱」、让问感情的人「定金再谈」，都是把财务话术套到别处。

边界：行动层给的是「往哪儿使劲」，不是「保证成」。页面明写医疗、法律、财务上的决定仍按现实规矩来——占卜不替用户拍板。

## 七、课格口径

课格（`buildKeGe`）回答的是「**这张盘整体长什么样**」。它与课体不是一个维度，这是本节最要紧的一句：

| | 回答 | 例子 |
| --- | --- | --- |
| 课体 | 三传是**怎么取出来的** | 元首、重审、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟 |
| 课格 | 这张盘**整体长什么样** | 曲直格（三传成木局）、进连茹、递生、禄入三传、六纯·纯阳、贵人逆布 |

所以课格**不改课体、不改分值、不随主题变**。分数仍由 §四 按类神算——加宽判据不动 `hepanCalibration` 那类分布锚点，这是分层的目的。

### 9 类判据（共 18 个格名）

| 类 | 判据 | 格名 |
| --- | --- | --- |
| ① 三传成局 | 三传恰见三合三支（三合全见才论，缺一支只是半合） | 曲直（木）/ 炎上（火）/ 从革（金）/ 润下（水） |
| ② 稼穑 | 三传皆土（辰戌丑未） | 稼穑 |
| ③ 连茹 | 三支在十二支上依次相连（间距恒为 +1 或 −1） | 进连茹 / 退连茹 |
| ④ 递生 / 递克 | 三传五行依次相生 / 相克 | 递生 / 递克 |
| ⑤ 得令 / 失令 | 以月建为司令，三传旺相 ≥2 / 三支全休囚死 | 三传得令 / 三传失令 |
| ⑥ 干支上神 | 日干上神与日支上神六合 / 相冲 | 干支上神相合 / 相冲 |
| ⑦ 财官印 | 三传六亲恰为妻财、官鬼、父母 | 三传财官印全 |
| ⑧ 禄 | 日干禄位（`GAN_LU`）落在三传 / 日辰上神 | 禄入三传 / 禄临日辰（互斥，只出一条） |
| ⑨ 贵人 | 恒有一条，作这层的底 | 贵人顺布 / 贵人逆布 |

### 三条纪律（都有测试盯）

1. **不许有「几乎恒真」的判据**。第一版把「失令」写成「休囚死 ≥2」——十二支里旺相恒只占四支，这条**在 576 张样本盘里 100% 成立**，等于每张盘都写「眼下只使得出一半」，把常态说成了不利。现在取两端：旺相 ≥2 才算得令，三支**全部**休囚死才算失令，中间态（1 旺 2 衰）是常态，不出。实测失令降到 17%。
2. **不许有「结构上不可达」的格**。曾写过「三传全空」：旬空恒为一对（如寅卯），三传三支要全落进去就必须有两支相同，而两支相同只出现在伏吟/返吟，其取传法又不与空亡对重合——**永远不可能命中**。已删，并留测试禁止复活。
3. **不许出「同一件事说两遍」的格**。「六亲全同」只可能发生在三传同五行，那必然已经是成局格（三合或稼穑）；「六亲三类全异」则是约六成盘的常态。两条都删了，只留「财官印全」。

### 分布基线（576 张样本盘：12 个月 × 4 日 × 12 时辰）

平均每盘 **2.87 条**，最多 7 条，只有一条（贵人顺逆）的占 10.2%。出现率区间 2.1%（炎上格）～51.4%（贵人顺布）——**没有任何一类接近恒真或恒假**，这是判据是否值得存在的实测门槛。

⚠️ 改动课格后重跑一次分布统计（`buildKeGe` 打点即可）：出现率 >70% 或 =0% 的判据要重新审，前者是套话、后者是死代码。

## 八、去套话口径

判据只有一句：**这句话，换任何一张盘还成立吗？** 成立就是套话。

说不清是因为没人量过。这里用的两个指标（`docs/divination-consistency.md` §6.5 有通用说明）：

- **槽位重复率**：把输出拆成「槽位」（`主题|advice`、`主题|evidence.课体·X`、`课格|格名`……），在 288 张样本盘上统计每个槽位最高频说法占比。**≥60%（样本≥12）即判定套话**。
- **整句重复率**：两张盘的全部文案按句号切分，算共有整句占较短一方的比例。三传与课体完全相同的两张盘「话接近」是对的，所以看的是**平均值**（<0.35）而不是最高值。

修复前后的实测（同一批 288 张盘）：

| 位置 | 修复前 | 现在 |
| --- | --- | --- |
| 课格 20 条 `plain` | 全是常量（uniq=1，100%） | 每条嵌三传支、步位、旺衰、方位 |
| `advice` | 静态档位表，爱情/亲情「平」档 69% 同句 | 档位原则 + 落点句 |
| 课体证据 | 90 张盘一字不差（「重审课：事从内部起…」） | 带这一次的三传与起手支 |
| 天将证据 | 21 张盘一字不差，且每条都复读「天将不改吉凶」 | 带落点（哪一步、哪一支），尾句删除 |
| 传空证据 | 16 张盘一字不差（写死「2 个落空」） | 点名哪几步落空 |
| 行动「无坑」分支 | 62% 同句 | 按气顺 / 有支得令 / 都没劲三分 |
| 行动「找人」回落分支 | 61% 同句 | 带贵人方位 |

现在：**≥50% 的槽位为 0 条，uniq=1 只剩免责与口径声明**，整句重复率平均 0.21。

⚠️ 两条踩过的坑：

1. **落点句只能讲结构，不能讲时机**。第一版落点句写「急不来，前面两步走完才轮到你」——可档位句在大吉时说「现在就谈」，两句在同一段里打架（真机截图才看出来）。现在落点只说「这一步在整条线的哪个位置、意味着什么」，旺衰与时机交给档位句和「月建·类神」那条依据。
2. **「不改吉凶」这类口径要在页面上说一次，不在每条依据里复读**。天将证据原来每条都带「天将只改气质与助力」，六条并排读就是噪音。

**为什么没有直接引依赖**：`liuren-ts-lib` 依赖 `tyme4ts`，本项目该包精确锁 `1.3.9`；新增依赖要重建 lock，而 `^` 版本会漂，且 `@ziweijs/*` 被上游撤下的前车之鉴说明「外部包随时会消失」。所以起课引擎按上述口径自研（约 500 行），把开源库当作**算法对照与验收基准**——`daliuren.test.ts` 里的锚点盘（甲午日申时，元首课，三传酉→辰→亥）就是手算 + 对照核过的那一例。

## 十、已知边界与流派差异

1. **贵人表**：本项目取通行口诀「甲戊庚牛羊」（甲日昼贵丑）。另有「甲羊戊庚牛」一系（甲日昼贵未），属流派差异，不采但已在代码注释标注。
2. **涉害深浅**：本实现计「归本位途中克我重数」，重数相同再比「我克」；部分流派只计克我，或另设「见机/察微/缀瑕」细目。
3. **课体细目**：`kinliuren` 有励德、三光、龙战、元胎、斫轮等大量杂课；本项目的**课体**只落到九宗门主干 + 结构课（伏吟/返吟/八专/别责），其余杂课不进课体，改以 §七 的课格做「气象」标注（只标不评）。二者不可混为一谈：把三光、官爵这类杂课塞进课体名，会和「三传怎么取」打架。
4. **应期粒度**：只到「支 + 相对月数/天数」，不到「某月某日必成」。原因见 §五：日期精度的来源（支数相加）本身站不住，给了就是假精确。另「填实/冲实」两说并存，本项目两条都算作候选窗口而非择一。
5. **禄表**：`GAN_LU` 取十干临官位（甲寅 乙卯 丙戊巳 丁己午 庚申 辛酉 壬亥 癸子），与八字「禄神」同表同源。**德神不采**：六壬「德」有天德/月德/日德三系，日德表各本互异（乙德在申或在午），无法统一，宁缺勿滥。
6. 农历子时换日按 `getDayInGanZhiExact`（23:00 起算次日），与八字页的晚子时流派开关不联动——两个模块的用途不同，不强行统一。
