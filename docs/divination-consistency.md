# 占卜三板块判读口径（六爻 / 梅花 / 灵签）

> 这份文档回答一个问题：**用户问「事业/爱情/亲情/财运/健康/学业」，三个板块凭什么给结论，且结论之间不会互相打架。**
> 代码出口：`src/utils/divinationCore.ts`（刻度与主题词表）、`liuyaoReading.ts`、`meihuaReading.ts`、`lotReading.ts`。
> 页面只渲染，不再自己判吉凶。

---

## 0. 改造前的问题（为什么必须收口）

| 板块 | 原状况 | 后果 |
| --- | --- | --- |
| 六爻 | 用神判据写在页面组件里，「综合断语」再写一遍，「大师解读」是 64 条静态文案 | 同一屏可以同时出现「用神得令，时机有利」与「宜守不宜攻」；健康题把官鬼旺当好消息（方向反了） |
| 梅花 | 只有体用生克 + 变卦，没有时令 | 同一卦在春天和冬天给同一句话；与六爻的月建判据对不上 |
| 灵签 | 「分维度解读」只按签等（上上/上/中/下/下下）套 4 段模板 | 所有上上签的事业解读一字不差；与上方「白话详解」里本签自己的注解互相矛盾；诸葛神数无等级 → 整块消失 |

三条共性问题：**判据分散、档位不统一、文案与判据脱钩**。

## 1. 统一吉凶刻度（唯一真源）

`verdictOf(score)`，score ∈ [-10, +10]：

| 分数 | 档位 | 语义 |
| --- | --- | --- |
| ≥ 6 | 大吉 | 底盘硬，可主动推进 |
| 3 ~ 5.99 | 吉 | 方向对，顺势能成 |
| -2.99 ~ 2.99 | 平 | 看你怎么使力 |
| -6 ~ -3 | 小凶 | 有阻滞，宜收不宜放 |
| ≤ -6 | 凶 | 逆风局，先保不失 |

阈值刻意设成「需要多个因子同时有利才算大吉」。三个板块的分数振幅：六爻约 ±12、梅花约 ±10、灵签约 ±6，都落在这个量纲里。

> ⚠️ 改阈值 = 改三板块全部产出分布。改前先跑 `divinationReading.test.ts` 的分布断言。

## 2. 六爻：用神力量 × 主题极性

### 2.1 判据链

```
取用神（按主题） → 单爻力量（月建/日辰/空/墓/动化/世应）
                → × 主题极性 → 加权平均 → 卦体合冲微调 → 档位 → 白话
```

### 2.2 力量因子权重

| 因子 | 判定 | 分 |
| --- | --- | --- |
| 月建 | 旺 / 相 / 休 / 囚 / 死 | +3 / +2 / −1 / −2 / −3 |
| 月破 | 月建冲用神支（无视旺衰，旺也当弱） | −4（覆盖月建分） |
| 日辰 | 同气或生扶 / 用神生日或克日 / 日克用神 | +2 / −1 / −2 |
| 日冲 | 用神旺 → 暗动；用神弱 → 日破 | +1 / −2 |
| 旬空 | 用神支落当日空亡 | −2 |
| 入墓 | 用神支为其五行墓库（木未/火戌/金丑/水辰/土四季） | −1 |
| 动化 | 回头生 / 回头克 / 进神 / 退神 / 泄气 / 比和 | +2 / −2 / +1 / −1 / −1 / 0 |
| 忌神动 | 另有动爻五行克用神 | −2 |
| 原神动 | 另有动爻五行生用神 | +1 |
| 持世 / 临应 | 用神落世爻 / 应爻 | +2 / −1 |
| 应生世 / 应克世 / 世生应 | 世应五行关系 | +1 / −2 / −1 |
| 卦体 | 六合卦 / 六冲卦 | 关系类 ±2，其余 ±1 |

六冲卦 = 八纯卦 + 天雷无妄 + 雷天大壮；六合卦 = 泰、否、豫、复、困、节、贲、旅。

### 2.3 主题极性（这一条最容易写错）

| 主题 | 取用 | 极性 |
| --- | --- | --- |
| 事业 | 官鬼 | +1 |
| 财运 | 妻财 | +1 |
| 爱情 | 男→妻财 / 女→官鬼 | +1 |
| 亲情 | 父母 0.7 + 兄弟 0.3 | +1 |
| 健康 | 官鬼（病势）1.0 + 子孙（解神）0.8 | **官鬼 −1**、子孙 +1 |
| 学业 | 父母 1.0 + 官鬼 0.5 | +1 |

> ⚠️ **健康是唯一反号的题**：官鬼旺 = 病势盛 = 凶。措辞表因此分成 `normal` / `disease` 两套（`CLAUSE`），
> 否则会写出「病势得令 → 事情当前时机有利」这种满口错话。
>
> ⚠️ **爱情必须分性别**：未设置性别时两星各半合看并显式说明，**不得默认男命**。

### 2.4 用神不上卦

取 `benGua.fuShen` 里的同名伏神：基础 −4，飞神生伏神 +1、飞神克伏神 −1，并在 `note` 里明说「已按伏神论」。

### 2.5 三合局：群体力量

单爻再旺，也怕对面成局来克；单爻再弱，成局也能翻盘。只看单爻会把「用神临月建但忌神三合成局」判得过于乐观。

口径依《增删卜易·三合章》：

> 「此三合者有四：一卦之内，有三爻动而合局者，一也。两爻动，一爻不动，亦成合局者，二也。有内卦初爻、三爻动，动而变出之爻成三合者，三也。有外卦四爻、六爻动，动而变出之爻成三合者，四也。」
> 「三爻若只两爻动，不为成局。须待后来之月日补凑，合成其局，谓之虚一待用。」

**成局条件（缺一不可）**

1. 三支齐现于「本卦六爻（含静爻）+ 变出之爻 + 月支 + 日支」这个集合
   —— **静爻可以充当第三支**（对应原文第二条「一爻不动亦成合局」）；
2. 其中**至少两支来自发动之爻**（本卦动爻或其变出之爻）
   —— 三爻全静不成局；只一爻发动、靠日月凑齐也不成局；
3. 局中任一支被月支或日支冲 → **破局**（冲散不成）。

| 局与用神的关系 | 分 |
| --- | --- |
| 局神五行 = 用神五行 | +3 |
| 局神生用神 | +2 |
| 局神克用神 | −3 |
| 不生不克 | 0 |
| 局被冲散 | 0（只写「有势无实」，不得加分） |

**世爻这一层**（原文：「用神旺则无不为吉，尤要世爻在局为美……若世爻不在局内，亦须局生世爻，始以吉断；倘局克世爻，则以凶推。」）

| 情形 | 分 |
| --- | --- |
| 世爻就在局中 | +1 |
| 世不在局内，局神生世 | +1 |
| 世不在局内，局神克世 | −2 |

> ⚠️ 世爻层的方向是**固定**的（克世恒凶），进 `strength` 前要先乘一次 `polarity`，
> 因为 `strength` 最后还会再乘一次——否则健康题会把「局克世」读成好消息。

### 2.6 卦变伏吟 / 反吟

比的是**本卦与变卦同一爻位的地支**，与八字层的「岁运同支＝伏吟」不是一回事。

| 现象 | 判定 | 分 |
| --- | --- | --- |
| 伏吟 | 同位地支全同（事在原地打转、动而不进） | 全卦 −2 / 单片 −1 |
| 反吟 | 同位地支全冲（翻来覆去、事与愿违） | 全卦 −2 / 单片 −1 |

优先判全卦，其次内卦（初二三），再外卦（四五上）。无变卦或变卦同名 → 不产生。

> ⚠️ `buildHeadline` 里顺序是 **月破 > 日破 > 旬空 > 伏神 > 伏吟反吟**。伏神（用神压根不上卦）比卦变层更基本，
> 不能因为出现伏吟就把「主角还没上台」这句话挤掉。

### 2.7 与开源实现的对照

| 项 | 本项目 | `najia-core`（GitHub） |
| --- | --- | --- |
| 三合局池 | 全卦六爻 + 变爻 + 日月 | 动爻 + 变爻 + 日月（静爻不入池） |
| 成局门槛 | **≥2 支来自发动之爻** | 三支在池中即成局（1 动亦可） |
| 伏吟反吟 | 全卦 / 内卦 / 外卦 三档 | 卦级 + 逐爻两级 |
| 六冲六合卦 | 固定名单（10 / 8 个） | 三对爻全冲/全合判定（与名单一致） |

> 差异处按《增删卜易》原文取严：原文明确要求「两爻动」才能成局，只一爻发动只能「虚一待用」。
> 静爻入池则是原文第二条明许的，开源库为简化略去了这一条。

## 3. 梅花：体用为主，时令加权

```
体用基础分（按主题分档） + 时令旺衰 + 变卦×0.5 + 互卦 + 卦象倾向 → 档位
```

### 3.1 体用基础分（**按主题分档，这是与旧实现最大的差别**）

| 关系 | 事业 | 学业 | 爱情 | 亲情 | 财运 | 健康 |
| --- | --- | --- | --- | --- | --- | --- |
| 用生体 | +4 | +3 | +3 | +3 | +3 | +3 |
| 体用比和 | +2 | +3 | **+4** | **+4** | +2 | +2 |
| 体克用 | +3 | +1 | **−1** | **−1** | **+4** | +1 |
| 体生用 | −1 | −1 | 0 | 0 | −2 | −2 |
| 用克体 | −4 | −3 | −4 | −4 | −3 | −4 |

> 「体克用」对**求财**最好（我克者为财），对**感情**最差（你在压对方）。
> 一张不分主题的表会把这两件事写成同一句话，用户一眼看出是模板。

### 3.2 其余因子

- **时令**：旺 +2 / 相 +1 / 休 −1 / 囚 −1 / 死 −2。月支取起卦当刻的节气月干支（`monthZhiOf()`），与六爻 `monthJian` 同源。
- **变卦**：按主题表 × 0.5 计入（结局倾向，不是当下格局）。
- **互卦**：取与体卦同五行的一卦为互体、另一为互用，按生克 ±1。
- **卦象**：用卦类象给 ±1（乾/震/巽利事业、巽/离利学业、兑/巽/离利感情、坤/乾/震/巽利亲情、坎皆不利；爱情里体用双阳卦再 −1）。

> ⚠️ 梅花不需要极性反转：**体卦恒代表求测者本人**，旺就是底气足。与六爻的差别来自「用神可能是病神」，不是来自刻度。

### 3.3 外应层：方位 / 应期 / 观物取象

这一层**不参与定吉凶**（不产生任何分数），只回答三个具体问题：往哪个方向使劲、大概什么时候见分晓、起卦当下该看什么。

| 产出 | 取法 |
| --- | --- |
| 有利方位 | 用卦 / 变卦用卦对体为「用生体」或「比和」→ 该卦的后天方位 |
| 回避方位 | 用卦 / 变卦用卦「用克体」→ 该卦的后天方位 |
| 应期（正法） | **卦气**：用卦五行 → 对应干支日（木=甲乙/寅卯、火=丙丁/巳午、土=戊己/辰戌丑未、金=庚辛/申酉、水=壬癸/亥子） |
| 应期（数字） | 按主题取数（见下） |
| 类象对照 | 体 / 用 / 互（上下卦各取前 3、前 2 象）/ 变（取变卦用卦之象） |

**应期取数按主题分档**（传统讲义口径）：

| 主题 | 算式 |
| --- | --- |
| 财运（测生意） | 上卦数 + 下卦数 |
| 健康（测病） | 主卦数 + 互卦数 + 变卦数 |
| 爱情 / 亲情（行人、寻人） | 上卦数 + 下卦数 + 动爻数 |
| 其余 | 上卦数 + 下卦数 + 动爻数 |

> 《梅花易数·卷二·先天后天论》：「又先天之卦，定事应之期，则取之卦气……后天则以卦数加时数。」
> 本项目的时间起卦、数字起卦都属于**先天起卦**，所以正法是**取卦气**；卦数只作「节奏参考」，
> 文案里必须写清「两者对不上时以卦气为准」，不能把数字说成精确到某天的预言。

后天方位：乾西北、兑西、离南、震东、巽东南、坎北、艮东北、坤西南。

> ⚠️ **外应不替用户编造**。凡写出「你今日必见红衣人」的都是假外应——本模块只给类象清单，
> `note` 原样说明「请自己对照当时所见」。测试钉住这句话必须存在。

## 4. 灵签：签等定基调，分项只在一档内微调

```
签等基线 → 本签分项（仙机 / 白话注解 / interpretation 行）±0.5 → 签诗语气 ±0.3 → 硬约束夹回
```

| 签等 | 基线 |
| --- | --- |
| 上上 | +6 |
| 上 | +4 |
| 中 | +1 |
| 下 | −3 |
| 下下 | −6 |
| （诸葛）不分等级 | 按签文语气推定 ±5 内 |

### 4.1 硬约束（自洽的底线）

`clampByLevel(score, level)`：

- `下下` → 最高只到 −3.01（**永远读不出「吉」**）
- `下` → 最高只到 1（最多「平」）
- `上上` → 最低不低于 3（**永远不会被读成「凶」**）

> 这条不是审美，是「下下签不能报大吉」的底线。有测试钉住。

### 4.2 分项来源优先级

1. 观音 `interpretations`（事业/感情/财运/健康）——本签自带，直接引用原话
2. 关帝 `interpretation` 里的「事业：… / 财运：…」行文本（解析为结构化）
3. 仙机（家宅/自身/求财/交易/婚姻/六甲/行人/寻人/公讼/疾病/失物）
4. **签诗意象**（`POEM_IMAGERY`，仅在该主题没有分项断语时兜底，权重 0.3）
5. 解签白话（诸葛神数无分项，**必须标注「按整段解签推」**）

主题 → 仙机键：事业→自身/交易/公讼；爱情→婚姻/行人；亲情→家宅/六甲/寻人；财运→求财/交易/失物；健康→疾病/自身；**学业→功名/自身/公讼**。

### 4.3 学业题：为什么需要「降级判据」

观音灵签的十五项仙机里**没有「功名／学业」这一项**（传统签谱只分家宅、自身、求财、交易、婚姻、六甲、行人、田蚕、六畜、寻人、公讼、移徙、失物、疾病、山坟）。若直接退到「仙机·自身」，学业题就只剩「诸事顺遂」式的泛论。

传统签谱的解法是看**签诗里有没有功名意象**——金榜、登科、丹桂、蟾宫、雁塔、夺标、甲第、青云、龙门、折桂、题名、读书、文章、笔、书。这些词出现在签诗里，本身就是这一签在讲功名。

| 顺序 | 判据 | label 写法 | 权重 |
| --- | --- | --- | --- |
| 1 | 结构化分项含功名/学业 | `签文分项·功名` | 0.5 |
| 2 | 仙机里有 `功名` 键 | `仙机·功名` | 0.5 |
| 3 | 签诗功名意象 | `签诗功名意象（**本签无学业专项断语**）` | 0.3 |
| 4 | 其余仙机（自身/公讼） | `仙机·自身` | 0.5 |
| 5 | 解签白话 | `解签白话（无分项断语…）` | 0.5 |

> ⚠️ 意象必须**引用整句**（`imageryQuote`），只甩一个「金榜」用户看不出它在诗里是什么语气。
> ⚠️ 这是**降级判据**，label 里必须写明「本签无学业专项断语」，不能伪装成仙机原文；权重也相应调低到 0.3。

## 5. 三板块主题落点对照

| 主题 | 六爻 | 梅花 | 灵签 |
| --- | --- | --- | --- |
| 事业 | 官鬼 + 世应 | 体用 + 用卦类象（乾/震/巽） | 分项·事业 / 仙机·自身 |
| 爱情 | 男妻财 / 女官鬼 | 体用 + 兑巽离 / 双阳卦扣分 | 分项·感情、婚姻 |
| 亲情 | 父母 + 兄弟 | 体用 + 坤乾震巽 / 兑口舌扣分 | 仙机·家宅、六甲、寻人 |
| 财运 | 妻财 | **体克用为最佳** | 分项·财运 / 仙机·求财 |
| 健康 | 官鬼（−）+ 子孙（+） | 体旺 + 用不克体 | 分项·健康 / 仙机·疾病 |
| 学业 | 父母 + 官鬼 | 体用 + 巽离 | 仙机·功名 / 签诗功名意象（降级） |

### 5.1 三板块结论**不要求一致**

硬把三块拉齐反而违背各自的命理逻辑——它们测的不是同一个对象：

| 板块 | 测的是 | 时间尺度 | 主判据 |
| --- | --- | --- | --- |
| 六爻 | 一件具体的事 | 当下（月日为主） | 用神旺衰 × 极性 |
| 梅花 | 我与这件事的关系格局 | 从起因到结局的过程 | 体用生克 |
| 灵签 | 这段时间的整体运势基调 | 较长（签等定调） | 签等 + 本签分项 |

所以要守的不是「跨板块一致」，而是三条：

1. **刻度同一把尺**——`verdictOf` 唯一；
2. **每块内部自洽**——依据 → 分数 → 档位 → 白话不打架；
3. **分歧可归因**——用户看到两块不同结论时，能从「判读依据」里指出差在哪一层（时间尺度？判据？取用？）。

> 如果三块永远给出同一个答案，那说明至少两块没在真正判读，只是在复述同一套模板。

## 6. 自洽不变量（测试钉住）

1. 三板块的 `verdict` 必须落在同一枚举 `大吉/吉/平/小凶/凶`。
2. `下下` 签不得出「吉/大吉」；`上上` 签不得出「凶/小凶」。
3. 同一张六爻盘：`事业 score > 健康 score`（官鬼为同一爻）。
4. 换盘 / 换主题 / 换签文，结论文案必须变化（反套话）。
5. 每条计分依据必须有「事实 + 意味」两段，不允许只甩术语。
6. 三合局：局神克用神必须压分（`weight < 0`）；被冲散的局 `weight = 0`，不得借它加分；三爻全静、或只一爻发动 → 不成局。
7. 三合局世爻层：世在局 +1、局克世 −2，且克世方向不随主题极性反转。
8. 伏吟/反吟：全卦力度必须大于单片；静卦不产生。
9. 梅花外应层不产分数，`note` 必须含「不替你编造」；应期必须给卦气（干支日）而不只给数字。
10. 灵签学业：意象证据权重 ≤ 0.3，label 必须含「本签无学业专项断语」。

对应测试：`src/utils/__tests__/divinationReading.test.ts`（50 条）、`src/pages/__tests__/divinationPages.test.tsx`（3 条页面冒烟）。

## 7. 不做的事（边界）

- 不引入「年月日时全盘」的流月流日细断——三板块仍是一次性占断。
- 六爻不做**多爻合断的复杂组合**（如多局并见、飞神伏神连环），只保留三合局（单局）+ 忌神/原神同动 + 卦变伏吟反吟。
- 灵签不做跨签比较（不排行、不推荐重抽到吉签为止）。
- 梅花不做体用之外的门派判法；外应只给类象对照表，**不推断具体场景**（不写「你会遇到一个穿灰衣的人」）。
- 健康结论一律附「这是盘面倾向，不是诊断」。
