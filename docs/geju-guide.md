# 八字与紫微斗数成格判定要点（口径文档）

本文档是 `src/utils/mingGe.ts`（八字命格）与 `src/utils/ziweiGe.ts`（紫微格局）的判定口径总览。
**改动任一引擎前先读本文档；改完必须同步 `mingGe.test.ts` / `ziweiGe.test.ts` 与本文档。**

## 一、八字成格判定（mingGe.ts）

判定顺序（前者命中即返回，后者不再论）：

```
特殊外格（天元一气 → 魁罡 → 日贵 → 金神 → 专旺 → 化气 → 从格）
  → 禄刃格（建禄 / 建禄月劫 / 羊刃）
  → 普通八格（月令藏干透干取格）
  → 衍生格（杀印相生等，覆盖格名与层次）
```

### 1. 特殊外格

| 格局 | 成格条件 | 备注 |
|---|---|---|
| 天元一气 | 四柱天干全同 | 个性极强，易固执 |
| 魁罡 | 日柱 ∈ {庚辰, 壬辰, 戊戌, 庚戌} | 只看日柱 |
| 日贵 | 日柱 ∈ {丁酉, 丁亥, 癸巳, 癸卯} | 日坐天乙 |
| 金神 | 时柱 ∈ {癸酉, 己巳, 乙丑} **且** 日主为乙/己 | 《三命通会》：六乙日六己日时逢方论，其余日主不论 |
| 专旺（曲直/炎上/稼穑/从革/润下） | 身强 + 月令当令 + 地支三会/三合局 + 无克星破格 | 土取辰戌丑未≥3；破格=天干透克星或地支克星≥2 |
| **化气**（2026-10 新增） | 见下节 | 五条件 + 真/假分层 |
| 从格（从财/从官杀/从儿） | 身极弱 + 旺神为财/官杀/食伤 | 见下节；判据唯一出口 `congGe.ts` |

### 2. 化气格判定要点（《三命通会》《滴天髓》口径）

**五个必要条件（全过为真化）：**

1. **天干五合相邻**：日干与**月干或时干**成五合（甲己/乙庚/丙辛/丁壬/戊癸）。年干隔位相合**不论化**。
2. **化神当令**：月支在化神当令（或生扶）之月——
   - 甲己化土：辰戌丑未（兼巳午火生土）
   - 乙庚化金：巳酉丑申
   - 丙辛化水：申子辰亥
   - 丁壬化木：亥卯未寅
   - 戊癸化火：寅午戌巳
3. **日主无根**：地支本气无比劫根、无印根；天干不透比劫印绶。
4. **化神旺**：地支化神五行 ≥2 位，或化神透干。
5. **无克破**：克化神之字不透年/月/时干（**日干自身是合化主角，弃本从化，不算破字**——这是实现时踩过的坑）。

**假化**（合化之意已成但不纯，且日主整体偏弱方论）：带根苗 / 化神弱 / 有虚克，三者居其一。
**争合妒合**（月干时干同为合神，如甲日己月己时）→ 合不专纯，**不论化**，走正格。
**失时**（非化神当令月）→ 不论化（如甲己合于卯月）。

**优先级**：化气在从格之前——身弱有合先论化，无合再论从。

**行运**：喜化神与生化神之地；忌克化神之字，岁运逢之有"化神还原"之应。真化多出身有底子，假化多白手起家、行运助化则变假成真。

### 2.1 从格判定要点（`congGe.ts` · 唯一出口）

> 从格是「喜忌整个反转」的分支，判错一格，用神/忌神/合盘/岁运吉凶全部跟着反。
> 判据只允许在 `analyzeCongGe` 里实现一次，`mingGe` 与 `recommendYongShen` 共用。

**前提**：日主 `身极弱`。不极弱不谈从。

**旺神取法（会局优先于月令本气）**：

1. 月支若与四柱另两支**凑齐三会方**，以**会局五行**论旺神——如戌在申酉戌中，土气尽泄于金，此时从的是金、不是土；
2. 否则以月支**本气五行**论旺神。

**从谁**：旺神为我克 → 从财；克我 → 从官杀；我生 → 从儿；旺神是印/比 → 不成从（另论从旺/专旺）。

**纯度**（`analyzeCongGe` 的 `purity`）：

| 判据 | 结论 |
|---|---|
| 有**本气比劫根**（地支本气十神为比肩/劫财） | **不成从** —— 硬门槛 |
| 无本气根，但天干透比劫/印，或藏干有比劫余气/印苗 | **假从** |
| 以上全无 | **真从** |

⚠️ **「有本气根即不从」不因该根被冲而放宽**：本气根（禄/刃/本气比劫）是实体之根，被冲只是受损、不是消失；「冲则假从」会把用神从「印比帮身」整个翻成「顺从旺神」——方向相反，代价远大于误判为假从。是否逢冲只写进理由链供展示，不作判定依据（判据宁先严后宽）。

⚠️ **判根一律用引擎已排定的十神**（`shiShenZhi` 下标 0 为本气；`shiShen` 为天干十神，日柱为「日主」），**不另抄五行表**——「地支本气十神是比肩/劫财」与「该支本气与日主同五行」等价，且天然兼容阴干阳干。

⚠️ **`recommendYongShen` 缺 `pillars` 时不进从格分支**（无从盘点根苗就判不了真/假从，宁可退回调候/扶抑也不猜）。调用方 `personChart.buildPerson` / `Bazi.tsx` / 评测夹具一律须传。

**历史坑**：旧实现是两份互不相同的判据——`mingGe` 只看「日支本气是否同五行」（根在时支/藏干一律漏），`recommendYongShen` 连根都不查。实测 2688 张盘中身极弱 401 张（14.92%），**旧口径把其中 100% 都判成从格**——引擎根本没有「身极弱但正格」这条出路。修正后 324 张判从（真从 4 / 假从 320 / 不成从 77），82 张盘的用神随之改变（全体 3.05%）。合盘分布锚点（`hepanCalibration` 400 对真实盘）**未受影响，无需重标**。

### 3. 禄刃格与普通八格

- **建禄**：月支 = 日干禄位。比劫成势（天干比劫≥2 或地支同气≥2）→ 建禄月劫。
- **羊刃**：月支 = 日干羊刃，**只论阳干**（阴干不论正羊刃）。
- **八格取格法**：月令本气透干 → 取本气格；本气未透看余气透干；杂气月（辰戌丑未）本气常为比劫，必须检查余气；都不透且本气属八格 → 取本气（标注"本气未透"）。
- **从格看月支本气十神**，不是月干十神。

### 4. 衍生格（互斥，优先级从高到低）

| 格局 | 条件 | 层次 |
|---|---|---|
| 杀印相生 | 七杀 + 正印/偏印 | 上等 |
| 伤官配印 | 伤官 + 正印 | 上等 |
| 伤官制杀 | 伤官 + 七杀同透 + 正官不透 + **日主有本气比劫根** | 中上 |
| 正官佩印 | 正官 + 正印 | 上等 |
| 官杀混杂·去留分档 | 正官 + 七杀**齐透天干**（硬门槛，藏干不计）→ 走 `guanShaHunZa.ts` 三道筛 | 上等～下等 |
| 食神生财 | 食神 + 正财/偏财 | 中等 |
| 财官相生 | 正财 + 正官 | 中等 |
| 比劫夺财 | 比劫≥2 透干成势 + 正财 + **无食伤通关** | 下等 |

⚠️ 比劫夺财必须成势才论——身弱财旺时一个比劫帮身反为喜，仅一个比肩透干就判夺财会大面积误伤。

⚠️ **官杀混杂判定唯一出口 `guanShaHunZa.analyzeGuanShaHunZa`**，必须排在「食神生财 / 财官相生」**之前**——否则「正官+七杀+财」齐透的盘会被财官相生拦走、真混杂漏判。分档：去杀留官（食神有力制杀，上等）/ 去官留杀（伤官有力制官 + 阳日须劫刃合杀，中上）/ 合杀留官（中上）/ 合官留杀（中等，合官不为贵降档）/ 混而有制（有救应但无力，中下）/ 官杀集结（身强能任，中等，不作混杂论）/ 混而无制（下等）。⚠️ **去留分工：去杀恒用食神、去官恒用伤官**，不取「伤官制杀 / 食神去官」；「有力」三关 = 有根 + 未被非官杀闲神合绊 + 无印夺食，**合官杀本身是「留」不是「绊」**。不设「官杀俱去」档——需官+杀+食+伤四干齐透，结构上不可能。详见 `docs/guansha-hunza.md`。

⚠️ **伤官制杀的门槛用「本气比劫根」而不是旺衰档**：旺衰五档会把「有羊刃但失令」的盘压成身极弱，而这类盘恰恰能驾杀（实盘 `丁酉 庚戌 甲申 丁卯`：时支卯为羊刃本气根、丁火伤官双透制庚，旺衰判身极弱，但结构上足以任杀）。正官同透时不取——伤官见官为下，不属「驾杀」。

## 二、紫微斗数成格判定（ziweiGe.ts）

**分层口径（中州派校准，2026-09 定稿）**：

- **硬门槛** = 主星结构成立 + 无破格 → 即入格。
- **加冕** = 吉星会照（昌曲辅弼魁钺）+ **禄权科引动或禄存** → 格局纯正；缺则成格但**层次打折**（reasons 注明），不判破格。
  （旧版把加冕当硬门槛，三方四正仅占全盘 1/3，三颗化吉星全落概率约 4%，几乎无人成格——校准记录见文件头。）
  ⚠️ 2026-10：**禄存计入加冕**。出处「与禄存、科权禄、左右、魁钺加会，则为极美之格」把禄存与四化并列，
  旧版只认四化，三方有禄存而无四化时白丢了这一层（理由文案写「禄存朝拱」）。
  ⚠️ 夹宫格的门槛**不跟着放宽**：那里要的是「引动」，禄存是静态星不是引动项，仍只认禄权科。

**破格分档（2026-10 依《全书》三档改制，只有「破格」真的删格）**：

出处：《紫微斗数全书》卷三〈论格星数高下〉「三方四正皆吉星为上格，吉凶相半守照为中格，凶星恶杀为下格」——
古法是**上／中／下三档**，不是"成／不成"两档。

| 档位 | 判据 | 处置 |
|---|---|---|
| 上格 | 无破格项 | 入格；有加冕则写「无破格，格局纯正」 |
| 中格 | 生年化忌落财帛/官禄、煞 1 颗、空劫 1 颗 | 仍入格，理由写「古法列为中格，成色减等（成因）」 |
| 下格 | 生年化忌坐命宫、煞 2 颗、空劫 2 颗分居 | 仍入格，理由写「古法列为下格，成色减等（成因）」 |
| **破格** | 生年化忌落迁移（冲命）、煞 ≥3、**空劫入命**、羊陀夹忌 | **不入格** |

- 源码只看 `brokenMain`（= `tier === 'broken'`）。⚠️ **不要**再用"有没有破格项"当门槛。
- 中/下格的说明写进**该格自己的 reasons**，不进 `breakReasons`——后者语义是"为什么没有格"，
  格已成立却挂一条破格警告，正是 2026-10 修过的那次文案割裂。
- ⚠️ **空劫入命 ≠ 空劫在三方四正**。写成"三方四正任一宫有主星又见空劫"实测命中 **36.2%**，
  等于变相退回一刀切（命宫三方四正几乎每宫都有主星）；只有空劫与**命宫**主星同宫才算破格。
- 化忌按落宫分轻重：冲命（迁移）最重、坐命次之、财官只减色。旧版不区分落宫，任意一宫全灭。
- 羊陀夹忌：命宫坐生年化忌且擎羊陀罗分居命宫两侧。化忌查主星+辅星（辛干文昌化忌落辅星，只查主星会漏判）。

⚠️ **两层口径（2026-10 修正）**：破格只**约束主星格**，夹宫格与火贪/铃贪属另两层判据，
不因破格被排除；真破格盘上这两类格的理由文案必须加「主星格已受破，此格属 XX 层，力度打折」，
否则用户会看到「破格」与「某格成立」同屏而以为自相矛盾。
⚠️ 实测：**昌曲夹结构成立的盘 124/124 全部带破格**（昌曲距离 2 只出现在寅/午/戌时，而这些时辰的空劫/火星位置恰好落在三方四正）。
若让夹宫格也受破格约束，等于直接删掉昌曲夹命/魁钺夹命/火贪/铃贪，故改为分层 + 措辞，而非连坐。

| 杀破狼 | **命宫或身宫坐杀/破/狼之一** + 三方四正见其中≥2（旧版只看三方数量，几乎人人成格） |

| 明珠出海 | 命宫在**未宫且无主星** + 三方四正会太阳太阴（离乡发迹、白手成家）。⚠️ 空宫按借对宫主星论，**不是缺数据** |
| 马头带箭 | 擎羊坐命于午宫。⚠️ 文案须两头讲：主威权外放，**亦主刚烈易折**，不要只写吉 |

> 上表自「禄马交驰」起为 2026-10 P1 补格。判据一律走 `tryGe`，成色与破格分档口径同主星格；
> 每格理由必须绑盘面事实（`tryGe` 的 `opts.basis`），**不接受"主星组合成立"一句套所有格**。

**突发吉格**：火贪 / 铃贪（2026-10 依出处重写判据，见 `docs/ziwei-ge-audit.md` §6.2）

- **落宫**：贪狼守 命宫／财帛／官禄／迁移／田宅／身宫（旧版只取命宫三方四正，漏田宅与身宫）。
- **星位**：同宫为**正格**；贪狼坐命宫、火铃在命宫三方四正相会为**次格**（「火星仅在三方相会…格局稍次」）。
  ⚠️ 次格**只在贪狼守命宫时成立**——弱档句子的主语是"守命宫"，不是"守六宫之一"。
  实测若把次格套到全部六个落宫，火贪从 83 盘涨到 306 盘（10.1%），会让"突发横发"变成全站最高频格。
- **破格**：**擎羊／陀罗与火铃同宫**（「擎羊火星同度、陀罗火星同度，均不合格」「只怕羊陀，遇之色灾成祸」）。
  羊陀只与贪狼同宫、不在火铃宫时属**减色**（「贪狼不喜与擎羊、陀罗同宫，易因色招灾」），不破格。
- **减色（不断格）**：空劫——「不怕空劫，空劫会贪狼，反能习正」，只减弱横发之力（成色打折）；贪狼化忌主「横发横破」。
  ⚠️ 旧版写的是"逢空劫同宫即破格"，**与原文相反**；实测 3024 盘里同宫带空劫 **0 盘**、带羊陀 29 盘——
  旧判据等于从没生效，该排的没排、不该排的白挂。
- 此破格只影响自身，不影响主星格（分层口径见上）。

**夹宫格**（昌曲夹命 / 魁钺夹命 / 左右夹命）：
- 必须分居命宫两侧（按地支相邻判定；同侧不算夹）；
- 夹宫之力弱，**须禄权科引动方足成格**，无引动只记 breakReason 不入格（刻意从严，与主星格的分层口径不同）。

## 四、十二宫深度解读：含无四化宫（ziweiPalaceDeep.ts，2026-10 新增）

**问题**：原「四化深度解读」只对带生年四化/自化的宫生成内容，一张真实盘通常只有 4~6 个宫有解读，
其余宫在深度层面是空白——用户看得到"化禄在哪、化忌在哪"，看不到"没被四化点到的宫到底怎样"。

**方案**：`getAllPalaceDeepReadings(gongData)` **十二宫全覆盖**，按十二宫顺序输出：

- 有四化的宫 → 直接返回 `ziweiSihuaDeep.generateSihuaDeepReading` 的结果（**口径唯一，不重复实现**）；
- 无四化的宫 → 生成固定四段结构：
  1. `本宫底色`：宫位领域（GONG_DOMAIN）+ 主星本质（STAR_NATURE）+ 该宫专属维度文案 + 庙陷亮度；空宫走借对宫论。
  2. `星曜组合的力道`：双星走 PAIR_TRAITS；单星讲纯与缺；群星讲聚焦；空宫讲"力道来自外部"；辅星分吉/煞。
  3. `三方四正的加持与牵制`：对宫 + 三合宫的坐星，说明外部环境。
  4. `未见四化的含义与经营方向`：说明"先天没有在这里下重注"，是中性底盘 + GONG_ADVICE 经营方向。

⚠️ **段数恒定为 4**（含空宫）——页面按段渲染，缺段会让不同宫的解读深度看起来不一致。
⚠️ 真实盘必有未涉四化的宫，测试用 `@ziweijs/core` 真盘断言"无四化宫段数 = 4 且各段非空"。

## 五、神煞「本局解释」（shenShaExplain.ts，2026-10 新增）

**问题**：`SHENSHA_PLAIN` 按名字取静态释义，同名同柱在任何盘上输出一字不差——
用户读不出"这颗煞在我的盘里到底怎样"。

**方案**：`explainShenSha(input)` / `explainShenShaMap(input)`，把 `shenShaPower` 的结构化因子
翻成盘面绑定的人话，五段递进：定位（落柱+干支+十二长生+档位）→ 作用领域（同柱十神）
→ 兑现条件（喜忌）→ 强弱交互（身强担得起／身弱要借力）→ 落空与制化。

**不变量**：同名神煞换柱位，解释必须不同（得地不同 → 定位句不同，柱位不同 → 阶段句不同）。
测试 `shenShaExplain.test.ts` 钉住该不变量。

## 六、命格判定依据与要素对应（mingGe.ts，2026-10 新增）

`analyzeMingGeDetailed` 除原有 `desc/details` 外，新增三件：

- `basis: string[]`：**判定依据链**——从「月令藏干/本气十神 → 是否透干 → 日主强弱/根气 → 结论」逐步推导，
  每步都落到具体干支与十神，让人看懂"为什么是这个格"。
- `keyFactors`：**要素对应表**（月令 / 天干透出 / 日主强弱 / 用神 / 格局）→ 本盘取值 → 对格局的作用。
  用神需通过第 5 个参数传入（页面已传 `yongRec.yongShen`）。
- `successKey`：**成败关键**（格局喜忌）——这个格靠什么成、怕什么破，按格局关键字分派（正官忌伤官见官、
  七杀喜制化、印格忌财坏印、财格忌比劫夺财、专旺忌官杀、从格忌印比、化气忌克化神……）。

⚠️ 改格局判定时，`basis` / `keyFactors` / `successKey` 要一起同步——三者是同一判定的三种表述。
⚠️ 页面 `Bazi.tsx` 里原先还有一份本地简化版命格实现（`MingGeResult`/`analyzeMingGe`），
   与 `mingGe.ts` 规则漂移且从未被调用，**已删除**；页面只消费 `mingGe.ts` 这一个真源。
