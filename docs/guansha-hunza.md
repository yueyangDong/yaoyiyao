## 一、它到底在说什么

十神里「克我者」有两种：**正官**（异性相克，如甲见辛）与**七杀**（同性相克，如甲见庚）。
两者功能重叠却性质相反——

| | 正官 | 七杀 |
|---|---|---|
| 象征 | 秩序、名分、体制内的约束 | 压力、竞争、非常手段 |
| 应对方式 | 守规矩、按流程 | 硬碰、走险、以技制暴 |
| 过旺时 | 拘束、保守、被压得没脾气 | 攻身、疾病、是非 |

「官杀混杂」指的是**这两种「管我的力」同时显形且互不相让**。古籍把它当作「格局不清」的一种，
因为子平法的核心审美是「一格清纯」——用神唯一、力量专一。

但要注意：**它不是「两个坏东西凑一起」这么简单**。若官杀都成了喜用，或者被有效制化，
反而是「官杀集结」的强力结构。这是下判断时最容易翻车的地方。

## 二、成立条件

### 2.1 第一道筛：是否「齐透天干」

《三命通会·官杀去留论》（卷五）：

> 盖言柱中官星七煞交差，月上见官时上见煞，或月上见煞时上见官，或四柱叠见……

后世据此编成歌诀：

> 官杀相连（年月相连）当论杀，杀官混杂各分垣（年时各分）。
> **露杀藏官而论杀，藏杀露官只论官。**
> 留官去杀莫遇杀，留杀去官休见官。

两个要点：

1. **藏者舍之、明者用之**——只有一位透干时，就以透出的那一位论，**不叫混杂**。
   地支藏了几个官杀，只要天干只透一个，仍以透者为主。
   （这一条现代论命基本一致：「地支的官杀混杂通通不叫官杀混杂」。）
2. **位置会影响结论**——「官杀相连当论杀」指年月两柱接连透官杀时倾向取杀；
   「各分垣」（年时分开、月时分开）才是典型混杂。此说在古籍中有，现代工具多不实现。

**结论：齐透天干是硬门槛，地支藏干不参与。**

### 2.2 第二道筛：有没有「去留」（取清）

《喜忌篇》：「杀官混杂类，有去官留杀，亦有去杀留官。」
《元理赋》：「去杀留官当论贵，去官留杀主威权。」

去留有四条路：

| 手段 | 机制 | 例（甲日主，辛官庚杀） |
|---|---|---|
| 合杀留官 | 他干合去七杀 | 乙木合庚 → 只留辛官 |
| 合官留杀 | 他干合去正官 | 丙/丁伤官去辛，乙合庚 → 留杀 |
| 食伤制 | 食神制杀 / 伤官制官 | 丙食神克庚（去杀留官）；丁伤官克辛（去官） |
| 印星化 | 官杀生印、印再生身 | 壬癸印透，杀势转为生扶 |

《三命通会》给了操作细则：

> 凡看去留，要详柱中官煞孰重孰轻。**天干透者易去，月支所藏者难去。**
> 须伤官食神去官煞之物，**众而有力**，方才去得。

并区分阳干阴干（这条很细，实现时容易做错）：

- **五阳日**：食神**能去杀、又能留官**；伤官**只能去官、不能留杀**，须得羊刃合才成去官留杀。
- **五阴日**：食神**只能去杀、不能留官**（日主自己能留官）；伤官**既能去官、又能留杀**。

**结论：有去留即取清，以所留者论格，不再叫混杂。**

### 2.3 第三道筛：日主能不能任

这里**流派分歧最大**，必须挑明：

| 流派 | 口径 | 出处 |
|---|---|---|
| 《三命通会》系 | 不设「身强豁免」，甚至明说「两停俱有扶合而无破害，**即是官煞混杂，反为贫贱**」 | 卷五原文 |
| 现代「喜用」派 | 身旺时官杀可能都是喜用 → 叫「**官杀集结**」，不算混杂；混杂多见于身弱盘 | 天机排盘公开文章 |
| 折中派 | 官杀各需**强根**（本气根/阳刃根）才算混杂；只有弱根（如丑中藏辛）不算 | 同上 |
| 古法补充 | 日主兼备**临官、帝旺**地支者可同时承受官杀，「人中龙凤」，不必去留 | 传抄体系，出处需再考 |

另有明确否定「身旺不怕混杂」的说法，认为那是后人附会、古无此论。
**这一点没有公认答案，实现时必须写明自己选了哪一派。**

### 2.4 判定流程（可执行版）

```
1. 取日干，定正官/七杀两个十神
2. 天干（不含日干）是否同时出现正官与七杀？
   ├─ 否 → 不构成混杂（地支藏干一律不计）
   └─ 是 → 进入 3
3. 是否有去留？
   ├─ 天干有合（合官或合杀）        → 取清，以所留者论
   ├─ 天干有食伤且「众而有力」      → 取清（制杀/制官）
   └─ 有强印通关（官杀生印印生身） → 取清（或降级为「混而有制」）
4. 无去留 → 看日主能否任
   ├─ 按 A 派：不论强弱，即判混杂
   └─ 按 B 派：身弱 → 判混杂；身旺 → 判「官杀集结」（中性偏吉）
5. 判混杂后，仍要注明是「混而无制」还是「混而有制（印轻/制轻）」
```

## 三、实际影响

### 3.1 古法断语（记录，但**不建议照抄进产品**）

传统命书按「透在哪些柱」给判词：

- 年干、月干混杂 → 「三十岁前一事无成」
- 月干、时干混杂 → 「主体弱多病」
- 年干、时干混杂 → 「主有妨子女」
- 「合官忘贵，合杀忘贱」——合去官星不主贵，合去七杀不主凶

这些是**断语体**，带有强烈的宿命论色彩，既无统计依据，也经不起现代审视。
本项目的纪律是：可以把「结构含义」讲清楚，**不复制这类判词**。

### 3.2 可解释的内核（现代叙述）

把玄学术语换成人话，官杀混杂的实质是**两套互不兼容的外部要求同时压在身上**：

- **决策内耗**：一条路要求按规矩来（正官），另一条要求破格硬闯（七杀）。同一个人身上两套 KPI，
  容易出现「想稳又不甘、想闯又怕」的摇摆，长期难在单一方向深耕。
- **压力结构**：约束来自两处，且互不背书，所以常感到「做什么都有人不满意」。
- **关系的两面性**：正官偏「名分与责任」，七杀偏「吸引力与强度」。
  传统女命以官杀为夫星，故有「明夫/暗夫」之说——**这是古法框架，不是对具体人的预言**。
  现代叙述应落到「容易被两种不同类型的特质吸引」，而不是「正缘难定」。
- **取清之后反而更好**：能合去一个、或制住一个，等于从「两套要求打架」变成「一套要求 + 一项技能」，
  往往表现为刚柔并济、能在复杂局面里协调。

### 3.3 与「伤官见官」的区别

容易混。二者都是「克我的星出问题」，但方向不同：

| | 官杀混杂 | 伤官见官 |
|---|---|---|
| 冲突方 | 正官 ↔ 七杀（同类相争） | 伤官 ↔ 正官（我生者克我之官） |
| 本质 | 两套约束打架、无主 | 我的表达冲撞既有秩序 |
| 有无制化 | 合/制/化皆可解 | 需财通关或印制伤 |

## 四、开源项目与商业工具怎么做

### 4.1 GitHub 上的开源实现

| 项目 | 语言 | 格局实现的形态 | 是否处理官杀混杂 |
|---|---|---|---|
| [zhiji-bazi](https://github.com/AmsonntagChow/zhiji-bazi) | TypeScript | `analyzePattern` 返回**单值枚举**（如 `zhengCai`），另有成败判定 | 枚举里没有组合格 → 未见 |
| [tianji](https://github.com/Zijian-Ni/tianji) | Python | 「根据月令透干判断格局（正官格、七杀格、食神格等）」 | 未见 |
| [bazi-engine](https://github.com/ruanxiaoer888/bazi-engine) | JS | 1000 条断语（标注古籍出处）+ 24 项神煞 | README 未提组合格 |
| [bazi-pan-skill](https://github.com/dglijin-oss/chinese-metaphysics-skills) | Python | 「格局判断（正官格、七杀格、食神格等 10 种格局）」 | 未见 |
| [Know-your-fate](https://github.com/tf1993614/Know-your-fate) | Python + Skill | 典籍参照式分析 | 未见代码级判定 |

**共性结论**：开源引擎普遍**止步于「月令取格 + 用神」**。
原因是月令取格有明确的、可枚举的算法（本气透干 → 余气透干 → 本气未透），
而「官杀混杂」属于**组合层判断**，需要同时看透藏、合化、制化、旺衰，
每个环节都有流派分歧，很难做成可复现的函数。

一个值得记下的旁证：zhiji-bazi 的 README 在「已知局限」里写——

> **格局判定有已知的假阳性。** 内部审计发现从格判得偏松，会把一些本该按正格论的盘判成从格。
> 那轮审计找到六个根因……现在比审计前收紧了，但不能说已经解决。

这跟本项目 2026-10 修「从格判据」时遇到的是**同一类问题**：
判据只看单个信号（月令本气）、不查根与去留，就会把正格误判成从格。
可见「组合层判据做得松」是这个领域的通病，不是个别项目的问题。

### 4.2 商业工具（测测 / 文墨天机）

必须说明边界：**这两家都是闭源产品，我读不到它们的源码，无法核实其判定逻辑。**
下面只是公开资料层级的观察，不构成对其实现的断言。

- **文墨天机**：以紫微斗数为强项，八字部分沿用传统子平框架；其公开内容多讲排盘与神煞，少见格局算法的细节披露。
- **测测**：面向大众的产品，输出偏「解读文案」而非「判据链」，通常不展示「为什么判成混杂」。
- **天机排盘（howzhan 系列文章）**：是目前公开资料里把「官杀混杂」口径讲得最系统的一支，
  明确提出「身旺可能是官杀集结而非混杂」「官杀各需强根才算混杂」「地支官杀不算混杂」。
  这属于**某一派的公开口径**，可以引用，但不能当作行业标准。

### 4.3 对本项目的启示

三条：

1. **别指望对齐商业软件**——它们大多不展示判据，对不上是常态，也没法当作验收标准。
2. **组合层判据必须有出处**——开源项目普遍回避这一层，正因为无出处就会变成拍脑袋。
3. **判据链路要能展示**——用户能看懂「为什么这么判」，比判得「准」更重要（本项目 `basis` 字段即为此）。

## 五、本项目的实现与实测

### 5.1 判据唯一出口

`src/utils/guanShaHunZa.ts` 的 `analyzeGuanShaHunZa(pillars, dayGan, strengthLevel)`，
由 `mingGe.ts` 的 `yanShengGe` 调用（插在「正官佩印」之后、`食神生财`/`财官相生`之前——
⚠️ 位置是判据的一部分，挪到后面会让「正官+七杀+财」齐透的盘被财官相生拦走，见 §5.3）。

决策顺序（先取清、后分档）：

| 顺序 | 判定 | 档位 |
|---|---|---|
| 1 | 阴日伤官有力克官，或阳日伤官克官**且有劫刃合杀** | 去官留杀（中上） |
| 2 | 阳日伤官克官但无劫刃合杀 → 不取清，记入理由链后继续 | — |
| 3 | 食神有力克杀 | 去杀留官（上等） |
| 4 | 杀被他干合住 | 合杀留官（中上） |
| 5 | 官被他干合住 | 合官留杀（中等，「合官不为贵」降档） |
| 6 | 无去留，但有制化手段且**无力** | 混而有制（中下） |
| 7 | 无去留且日主身强/身极强 | 官杀集结（中等，不作混杂论） |
| 8 | 无去留、无救应、身弱 | 混而无制（下等） |

三条实现要点：

- **去留分工**：去杀恒用**食神**、去官恒用**伤官**。不取「伤官制杀 / 食神去官」——
  五行上虽克，但不在去留体系内（食神/伤官的五行必克杀/官，是「我生者克克我者」的结构必然，
  所以 `WX_KE` 校验只是防御性的）。
- **「有力」三关**：有根（地支本气或藏干同五行）、未被**非官杀的闲神**合绊、无印夺食。
  ⚠️ 合官杀本身不算绊——阳日食神的五合对象恒为正官、阴日伤官恒为七杀，那是「留」不是「绊」。
- **不设「官杀俱去」档**：需官 + 杀 + 食 + 伤四干齐透，四柱除日干仅三干，结构上不可能。
  阳日的「去官留杀」（需官+杀+伤+劫）同理，代码保留分支但实际不可达。

### 5.2 修复前后的对照（甲日主，均传「身弱」）

| 盘 | 天干 | 应判 | 修复前 | 修复后 |
|---|---|---|---|---|
| A 齐透·无去留 | 辛 庚 甲 己 | 混而无制 | 七杀格·财官相生（中等） | **混而无制（下等）** |
| B 乙合庚 | 辛 庚 甲 乙 | 合杀留官 | 官杀混杂（下等） | **合杀留官（中上）** |
| C 官透杀藏 | 辛 戊 甲 己 | 不构成混杂 | 财官相生 | 不构成（`tier=null`） |
| D 壬印透 | 辛 庚 甲 壬 | 取清→杀印相生 | 杀印相生（上等） | 杀印相生（上等，前置拦截） |
| E 丙食神制杀 | 辛 庚 甲 丙 | 去杀留官 | 官杀混杂（下等） | **去杀留官（上等）** |

修复前的三条缺陷（现已全部修掉，记录在此防回归）：

1. **优先级短路**：`财官相生` 排在混杂判定之前 → A 盘真混杂漏判。
2. **该取清的被判成混杂**：B、E 本可通过合杀、制杀取清，却直接落「下等」——双向都错，
   而且错得更糟：把有解的结构说成死局。
3. **成败关键错配**：`successKeyOf` 无混杂分支，输出基础格文案（「七杀格喜印星化杀」）；
   旧文案还自相矛盾（既判「下等」又说「需印星化解」）。

### 5.3 全量分布（3024 盘：1990–2010 每月 3 天 × 4 时辰）

官杀齐透（构成混杂判定）**181 盘，占 5.99%**。各档占齐透盘的比例：

| 档位 | 盘数 | 占比 | 实盘例 |
|---|---|---|---|
| 混而无制 | 112 | 61.9% | 己巳 丙子 庚午 丁丑（身弱） |
| 去杀留官 | 23 | 12.7% | 庚午 丙戌 甲戌 辛未（身极弱） |
| 官杀集结 | 14 | 7.7% | 辛未 壬辰 乙卯 庚辰（身强） |
| 合杀留官 | 13 | 7.2% | 辛未 庚寅 甲戌 乙丑（身强） |
| 混而有制 | 9 | 5.0% | 乙亥 甲申 戊子 丙辰（中和） |
| 去官留杀 | 8 | 4.4% | 戊寅 甲寅 癸未 己未（身极弱） |
| 合官留杀 | 2 | 1.1% | 戊寅 己未 癸亥 癸丑（身极弱） |

读法与注意：

- 「齐透」只占 6%，与「官杀混杂并不多见」的常识相符；其中六成是无救应的混而无制——
  这符合古法「混杂多不足贵」的观察，但也意味着**「混而无制」是这一档的默认脸**，
  文案必须给出路子（去一留一、岁运印化/食制/合杀），不能只贴标签。
- 合官留杀（1.1%）与去官留杀（4.4%）明显偏少，因为阴日伤官的条件比食神制杀窄。
- ⚠️ 本次改动**不影响合盘 200 分锚点**（`hepanCalibration` 400 对盘全绿），
  也不改 `recommendYongShen`——格局层与用神层解耦，只有展示文案与格名变化。

### 5.4 同一组四柱，只改一个字

以 A→B 为例，**只把时干从「己（正财）」换成「乙（劫财）」**：

- A：官杀齐透无解 → 混而无制，需要印或食伤来救；
- B：乙木合去庚杀 → **合杀留官**，辛官独清，格局反而专一。

同一个人、同一组地支，结论从「两套要求打架」变成「一套要求 + 一项化解手段」。
这类「差之毫厘」正是三道筛必须全部实现的原因——只做第一道，就会把 B 判成 A。

## 六、结论与注意事项

### 结论

1. **官杀混杂 = 齐透天干（硬门槛）+ 无去留 + 日主不能任**，三者同时成立才谈得上「混杂」。
   地支藏干不参与；一藏一透不构成。
2. **去留优先于强弱**。先看有没有合、制、化；有则取清，不谈混杂。
   《三命通会》给阳干阴干两套细则（食神/伤官能否留官留杀不同），实现时不能一刀切。
3. **身强弱是否作为门槛是流派分歧**，必须自选并写明。本项目取折中口径：
   不设身强弱硬门槛，用「官杀集结」这一档承接身强盘（A 派不设豁免、B 派身旺论集结，两边都不丢）。
4. **它不是一个「凶格」标签**。有制化则成器，无制化才是内耗。
   把结构说明白，比贴「下等」有用得多。

### 注意事项

- ⚠️ **别把「下等」当结论**。格局层次是结构评价，不是对人的评价。已修的旧实现直接给「下等」
  且同时输出「压力与机遇并存，需印星化解」——自相矛盾（既说下等又说有救）。现文案改为
  结构叙述 + 出路（去一留一 / 岁运印化食制合杀），不再只贴标签。
- ⚠️ **古法判词不可照搬**。「三十岁前一事无成」「体弱多病」「妨子女」这类断语没有统计基础，
  写进产品就是把玄学包装成恐吓。
- ⚠️ **女命的「明夫/暗夫」要慎用**。这是古法框架下的夫妻星取象，落到具体人身上很容易
  变成对婚姻的判决。本项目纪律：性别语义只在 `liunianInteraction.loveNote` 里按 gender 分支，
  共用十神表不写性别。
- ⚠️ **流派必须标口径**。同一张盘，格局派、旺衰派、盲派可能给出相反结论。
  对外表述时说清楚「这是哪一派的口径」，比声称「正确」更诚实。
- ⚠️ **组合层判据要有出处**。开源项目普遍不碰这一层，正因为它没有可枚举的标准答案。
  新增判据时，先在本文档写下出处与取舍，再改代码。
