## 这份文档解决什么

旧口径的硬伤：`calcShenSha` 是**纯布尔命中**（命中即算，0/1），下游文案按**名字**索引，
于是两张只共享一颗弱煞的盘会输出同一段解读 —— 表现为「不同命盘被判高度重合」。

**实测（3000 张真实命盘，1935–2005，seed 20261004）：**

| 指标 | 旧口径（计共同神煞个数） | 新口径（加权 Jaccard） |
|---|---|---|
| 每盘命中神煞（去重名字） | 平均 14.93 | 同左 |
| 两盘共享神煞（中位） | 6 | — |
| 判为「高重合」的盘对占比 | **93.9%**（共同 ≥3） | **5.0%**（≥0.30） |
| 判别力 | 接近 0 | 提升约 19 倍 |

## 力量模型：power = clamp(宫位 × 得地 × 空亡 × 制化 × 喜忌, 0, 1)

| 因子 | 取值 | 依据 |
|---|---|---|
| 宫位 | 月支/日支 `1.0`，年支/时支 `0.6` | 月令与日支是命局重心 |
| 得地 | 该柱地支对日干的十二长生宫：临官/帝旺 `1.0`、长生 `0.9`、衰 `0.7`、死 `0.4`、绝 `0.3` | 神煞须有根才发力 |
| 空亡 | 落本旬空亡 `0.35`；「空亡」这颗煞自身不受自指影响 | 有名无实 |
| 制化 | 取最强制化一档：冲 `0.4`、合 `0.55`、刑 `0.75`、害 `0.8`（**不连乘**） | 冲则贵人力散；连乘会过度归零 |
| 喜忌 | 吉煞落用神 `1.0` / 未落 `0.7`；凶煞落用神 `0.85` / 未落 `1.0`；平煞 `0.85` | 吉神为忌则福不实；凶煞得用则凶性稍减 |

`power` 表示**发力强度**，不含吉凶方向——方向由 `type`（吉/凶/平）承载。

### 刻意不建模的三件事（别当成漏做）

- **忌神**：项目里 `yongShen` 只是一组五行，没有权威忌神列表，硬推会造出伪精度。
- **岁运引动**：神煞引擎只跑原局，原局自带 vs 流年引动不做区分。
- **透干加成**：绝大多数神煞本就是支位判定。

## 相似度：加权 Jaccard（Ruzicka）

```
sim = Σ_name min(wA, wB) / Σ_name max(wA, wB)     （对两盘神煞名的并集求和）
w   = 该煞在本盘中最强一处的 power（同名多柱取 max，不求和）
```

- 两边都命中且都强 → 逼近 1；只有一边命中、或命中但很弱 → 逼近 0。
- 共用 3 颗 0.1 的弱煞（旧判据说"高重合"）→ 实测 score 0.077，判「低」。

## 阈值是量纲锚点，改系数必须连带改

| 常量 | 值 | 标定依据 |
|---|---|---|
| `SHENSHA_POWER_BANDS` | strong `0.40`、medium `0.20` | power 分布 p70 / p30 |
| `SHENSHA_SIMILARITY_BANDS` | high `0.30`、medium `0.22` | 相似度 p95 / ≈p79 |

power 分布分位：p30 `0.20`、p50 `0.28`、p70 `0.40`、p90 `0.60`。
相似度分布分位：p50 `0.158`、p90 `0.264`、p95 `0.300`、max `0.815`。

**改动流程：**
1. 改 `shenShaPower.ts` / `shenShaSimilarity.ts` 的系数；
2. 跑一次临时探针，重新打印 power 与 similarity 的分位数；
3. 按新的分位数更新阈值常量与测试里的**区间**断言；
4. `npx tsc --noEmit && npx vitest run`。

⚠️ 测试用**区间**而非精确值断言：`lunar-typescript` 在 package.json 里是 `^1.6.0`，
CI 装到 1.7.x 可能让分布微移，精确断言会假红。

## 合盘满分口径变更（v4，2026-10-04）

| | 旧（v3） | 新（v4） |
|---|---|---|
| 项数 | 7（八字 5 + 紫微 2） | **8**（八字 6 + 紫微 2） |
| 满分 | 140 | **160**（`HEPAN_MAX_SCORE`） |
| 档位阈值 | 93 / 76 / 58 | **114 / 101 / 90** |

⚠️ **阈值不是等比换算来的**（106/87/66 已实测否决：会让"天作之合"32.7%、"需磨合"0.2%）。
测法：600 对真实合盘（seed 20261006）取分位数 p90 / p55 / p15。
定标后占比 10% / 37.7% / 37.3% / 15%——旧口径是 38.7% / 54.7% / 6.7% / **0%**，
最高档近四成、最低档不可达，两个档位都失去意义，所以借这次满分必变的机会一并修正。

分布回归在 `src/utils/__tests__/hepanCalibration.test.ts`（区间断言，改权重/阈值必红）。
