# 命格与紫微格局详细判定设计文档

> **日期：** 2026-08-27
> **状态：** 已确认（用户批准）

## 1. 背景与目标

现状：八字页 `analyzeMingGe` 只判建禄格/羊刃格（简陋）；紫微页无格局概念。用户要求：
- 八字：按传统格局体系写出详细的格（普通八格 + 禄刃格 + 特殊外格 + 衍生格 + 层次），并输出**用神/忌神是否透干（含柱位）**
- 紫微：按严格条件判定成格（核心主星组合 + 吉星会照 + 四化引动 + 无破格），成格显示格名

**原则**：格局是辅助工具，输出需配白话解释，不改变既有排盘算法与展示结构。

## 2. 八字命格（`src/utils/mingGe.ts` 新增纯函数模块）

### 2.1 判定顺序（外格优先）

```
1. 特殊外格（先论外格）
2. 禄刃格（建禄/羊刃）
3. 普通八格（月令藏干透干定格）
4. 衍生格（八格基础上按十神组合）
5. 层次（上/中/下）
```

### 2.2 特殊外格

| 格 | 条件 |
|---|---|
| 天元一气格 | 四柱天干完全相同 |
| 魁罡格 | 日柱为 庚辰/壬辰/戊戌/庚戌 |
| 日贵格 | 日柱为 丁酉/丁亥/癸巳/癸卯 |
| 日德格 | 日柱为 甲寅/丙辰/戊辰/庚辰/壬戌 |
| 金神格 | 时柱为 癸酉/己巳/乙丑 |
| 专旺·曲直格 | 日主甲乙木 + 月令寅卯辰 + 局中木气最旺 |
| 专旺·炎上格 | 日主丙丁火 + 月令巳午未 + 火气最旺 |
| 专旺·稼穑格 | 日主戊己土 + 月令辰戌丑未 + 土气最旺 |
| 专旺·从革格 | 日主庚辛金 + 月令申酉戌 + 金气最旺 |
| 专旺·润下格 | 日主壬癸水 + 月令亥子丑 + 水气最旺 |
| 从格·从财/从官杀/从儿 | 日主极弱（身极弱）且月令为财/官杀/食伤旺地，从最强五行 |

> 实现提示：专旺/从格判定用现有 `wxStats`（五行统计）与 `strengthLevel`；月令归属按地支本气五行。

### 2.3 禄刃格（保留现有逻辑）

- 建禄格：月支 = 日干禄位（甲寅/乙卯/丙巳/丁午/戊巳/己午/庚申/辛酉/壬亥/癸子）
- 羊刃格：月支 = 日干羊刃位（甲卯/乙寅/丙午/丁巳/戊午/己巳/庚酉/辛申/壬子/癸亥）

### 2.4 普通八格（月令藏干透干定格）

- 月支藏干 → 各藏干对日干的十神
- 定格优先级：**本气透干** → **余气透干** → **月令本气**
- 八格：正官格/七杀格/正印格/偏印格/正财格/偏财格/食神格/伤官格
- 月令为比劫（本气十神为比肩/劫财）时 → 不取八格（走禄刃格或月令本气标记）

> 藏干十神数据：现有 `p.cangGan`（月柱藏干）+ `p.shiShenZhi`（地支十神）可直接复用。

### 2.5 衍生格与层次

在八格基础上按四柱十神组合判定（互斥，优先级从高到低）：

| 衍生格 | 条件 | 层次 |
|---|---|---|
| 杀印相生 | 七杀 + 正印/偏印（透干或同柱） | 上等 |
| 伤官配印 | 伤官 + 正印 | 上等 |
| 正官佩印 | 正官 + 正印 | 上等 |
| 官印双清 | 正官 + 正印均透干 | 上等 |
| 食神生财 | 食神 + 正财/偏财 | 中等 |
| 财官相生 | 正财 + 正官 | 中等 |
| 比劫夺财 | 比肩/劫财旺 + 财星弱 | 下等 |
| 官杀混杂 | 正官 + 七杀同现（透干） | 下等 |

无衍生格时：八格基准层次 = 中上（正官/正印格）或 中（其余）。

### 2.6 输出

```ts
export interface MingGeResult {
  geName: string;      // 如「正官格·杀印相生」
  geType: string;      // 如「普通格」|「外格」|「禄格」
  score: string;       // 上等/中上/中等/中下/下等
  desc: string;        // 白话解释
  details: string[];   // 判定依据 + 用神/忌神透干说明
}
```

### 2.7 用神忌神透干

- 输入：四柱 `tianGan` 数组、用神五行（`yongShen`）、忌神五行（`xiShen`，实为忌神）
- 判定：天干五行与用神/忌神五行相同 → 透干；记录柱位（年干/月干/日干/时干）
- 输出到 details：`用神木透干（年干甲、日干乙）` / `用神木不透干`；忌神同理

## 3. 紫微格局（`src/utils/ziweiGe.ts` 新增纯函数模块）

### 3.1 输入

`ziweiData.gongData`（宫位数组：name/majorStars[{name,sihua}]/minorStars[string]）、`mingGongName`

### 3.2 主星格（命宫 + 三方四正 = 命宫/财帛/官禄/迁移）

| 格 | 核心组合 |
|---|---|
| 机月同梁格 | 天机/太阴/天同/天梁 汇于命三方 |
| 杀破狼格 | 七杀/破军/贪狼 汇于命三方 |
| 紫府同宫格 | 紫微/天府 同宫于命宫 |
| 日月并明格 | 太阳/太阴 同在旺地 |
| 府相朝垣格 | 天府/天相 分居命宫与官禄宫 |
| 廉贞贪狼格 | 廉贞/贪狼 同宫或对拱 |

### 3.3 杂耀格（命宫夹宫 = 相邻两宫）

| 格 | 条件 |
|---|---|
| 昌曲夹命格 | 文昌/文曲 分居命宫左右 |
| 魁钺夹命格 | 天魁/天钺 分居命宫左右 |
| 左右夹命格 | 左辅/右弼 分居命宫左右 |

### 3.4 成格条件（严格）

主星组合成立的前提下，**全部满足**才算成格：
1. **吉星会照**：文昌/文曲/左辅/右弼/天魁/天钺 至少 1 颗在命三方四正
2. **四化引动**：命三方四正内至少 1 星带 生年四化 禄/权/科
3. **无破格**（任一出现即破格，不计入成格）：
   - 命三方四正内出现 **化忌**（生年忌）
   - 煞星（擎羊/陀罗/火星/铃星）≥ 2 且组合不佳（简化：≥ 2 即破）
   - 空亡星（地空/地劫）≥ 2（简化：命宫或三方四正 ≥ 2 即破）

### 3.5 输出

```ts
export interface ZiweiGeResult {
  geNames: string[];     // 成格的格名列表（可能多个）
  reasons: string[];     // 每格的判定说明
  breakReasons: string[]; // 未成格/被破的原因
}
```

### 3.6 展示

紫微结果区新增「格局」CollapsibleCard：成格显示格名 + 说明；未成格显示"未构成特殊格局" + 破格原因。
