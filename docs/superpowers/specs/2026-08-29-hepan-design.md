# 情侣合盘功能与解释词优化设计文档

> **日期：** 2026-08-29
> **状态：** 已确认（用户批准）

## 1. 背景

开源调研发现合盘主流思路：八字合婚（日主五行生克、地支合冲刑害、纳音生克、生肖六合三合、喜用神互补）+ 紫微合盘（命宫主星配合、三方四正吉星、四化互动），分项打分加权总分。参考项目：`china-testing/bazi`（合婚）、`hhszzzz/taibu`（合盘配对）、`Ficere/tianji`（合盘评分）、`Renhuai123/ziwei-doushu`（格局知识库）。

## 2. 合盘功能

### 2.1 入口与输入
- 首页新增「情侣合盘」入口（功德箱下方）
- 本人信息从当前档案自动带入（未建档则提示先去创建档案）；对方信息手动输入（年/月/日/时/分/性别/出生地，公历+农历切换，复用八字页表单样式与校验）
- 校验：日期合法、不能未来（复用 dateValidation）

### 2.2 合盘算法（`src/utils/hepan.ts` 纯函数模块）

输入：双方 `PillarData[]` + 双方日主五行 + 生肖 + 纳音 + 紫微 `gongData`（对方）——本项目已有数据生成能力。

输出：`HePanResult { totalScore: number; items: { title: string; score: number; desc: string }[]; summary: string }`

**八字部分（五项，各 0-20 分）**：
1. **日主五行**（20）：相生（我生你/你生我）高分，比和次之，相克低分
2. **地支关系**（20）：六合/三合数 − 冲刑害数，折算
3. **纳音**（20）：纳音五行相生加分
4. **生肖**（20）：六合满分，三合次之，六冲零分
5. **喜用神互补**（20）：对方日主五行 = 我方喜用神则满分

**紫微部分（两项，各 0-10 分，共 20）**：
1. **命宫主星配合**（10）：双方命宫主星五行相生/吉星互照
2. **四化互动**（10）：对方四化星（禄/权/科）落我方命三方加分，忌星减分

**总分**：100 分制，分档：≥80 天作之合 / 65-79 良缘 / 50-64 平常 / <50 需磨合。

**每条 desc 由具体数据生成**（不同组合不同文案，禁止重复模板）——desc 生成函数接收实际值（五行对、合冲数、生肖对）拼装。

### 2.3 页面 `src/pages/HePan.tsx`

- 路由 `/hepan`，懒加载
- 布局：本人信息卡（只读）+ 对方表单（复用校验）→「开始合盘」按钮
- 排盘过程：`DivinationOverlay` 全屏动画，用**用户提供合盘参考图**（裁切圆形图案 `src/assets/hepan-art.png`，旋转展示）
- 结果：总分圆环（antd Progress）+ 分项卡片（标题/分数/描述）+ 综合建议

### 2.4 加载动画素材

用户参考图（2048×2048，合盘圆形图案）→ 裁切中心圆形 → 压缩 600×600 → `src/assets/hepan-art.png`；`DivinationOverlay` 增加可选 `artSrc` prop（默认现有水墨图，合盘页传 hepan-art）。

## 3. 解释词去重（分项解读）

### 3.1 八字分项
- **流年/流月 desc**：当前"比和/印星/食伤/官杀/财运"模板每项只有一句话且循环重复 → 每项准备 2-3 个变体，按年/月下标轮换（`descPool[type][idx % len]`）
- **大运解读**：`getDayunInterpretation` 同样加变体池

### 3.2 紫微分项
- **宫位解读**（`getGongExplanation`）：verdict 文案数组已有多条（随机）→ 改为按宫位名哈希确定性选择 + 扩充数组（每类 4-5 条）
- 避免"同一句话在多个宫位重复"：文案带宫位名与具体星曜名
